- We have many way to setup k8s cluster like cloud managed service like EKS, GKE, ... 
it manage the control plan, we register worker node to join a cluster, it fast and high scalable based on cloud provider trust
- Or we can use docker based tool like `kind`, `minikube (not support cluster)`, `k3s`, `k3d (k3s but in docker container)`
- But for harder stuff and understand the layer below i choose k3s 


- https://kubernetes.io/docs/setup/production-environment/tools/kubeadm/ha-topology/
- https://dockerlabs.collabnix.com/kubernetes/beginners/Install-and-configure-a-multi-master-Kubernetes-cluster-with-kubeadm.html
- For HA we need multi master node, if we choose stacked etcd, use at least 3 three master node (Raft consesus related), or external etcd store
- https://www.truefullstaq.com/en/blog/k3s-home-cluster (k3s)
